# المسبحة الإلكترونية - Digital Tasbih

تطبيق أندرويد خفيف يعمل تمامًا دون إنترنت.

## المميزات
- زر ضغط كبير في وسط الشاشة
- خيار "الضغط على كل الشاشة" من الإعدادات
- حفظ العدد تلقائيًا (حتى بعد إغلاق التطبيق)
- صوت واهتزاز عند كل ضغطة (قابلة للإيقاف)
- زر إعادة التعيين
- تصميم عصري بحجم صغير
- يدعم أندرويد 5.0 (API 21) فأعلى

## طريقة البناء
1. افتح Android Studio.
2. File → New → Import Project واختر مجلد المشروع.
3. انتظر اكتمال مزامنة Gradle.
4. لتشغيل التطبيق على هاتفك: وصّل الهاتف عبر USB مع تفعيل "تصحيح USB"، ثم اضغط Run.
5. لإنشاء ملف APK: Build → Build Bundle(s) / APK(s) → Build APK(s). يُنشأ الملف في `app/build/outputs/apk/debug/app-debug.apk`.

## هيكل المشروع
- `app/src/main/java/.../MainActivity.kt` — منطق التطبيق
- `app/src/main/res/layout/activity_main.xml` — واجهة المستخدم
- `app/src/main/res/values/` — الألوان والنصوص والثيمات
- `app/src/main/res/drawable/` — الخلفيات والأيقونات
- `AndroidManifest.xml` — إعدادات التطبيق والأذونات

التطبيق لا يحتاج إلى أي اتصال بالإنترنت ويعمل بالكامل على الجهاز.
